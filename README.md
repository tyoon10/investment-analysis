# Investment Analysis

Jupyter notebooks for financial markets analysis — options pricing, Korean market data, and portfolio optimization.

## Notebooks

| Notebook | Description |
|----------|-------------|
| `230509 Options Expiration Calendar.ipynb` | Options expiration calendar analysis and visualization |
| `KRX Market Data Import.ipynb` | Importing and processing Korea Exchange (KRX) market data |
| `Optimal Portfolio Simulator.ipynb` | Mean-variance portfolio optimization and efficient frontier simulation |

## Topics

- Portfolio optimization (mean-variance, efficient frontier)
- Options pricing and expiration analysis
- Korean equity market data (KRX)

## Requirements

- Python 3.8+
- Jupyter Notebook
- pandas, numpy, matplotlib, scipy
